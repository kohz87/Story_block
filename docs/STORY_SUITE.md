# Story Suite

Story Block hosts Story Director and other registered modules. Story Director provides the clock, calendar, map, story threads, standalone checks, World, Chronicle and optional arc planning. NPC State Delta is optional; when present, the modules can share people and social context through guarded queries.

Story Block owns state, change-line capture and the shared interface. Other modules register commands, queries, features and screens through the SDK. See `docs/v2/SPEC.md` and `docs/v2/MODULES.md` for the module API and the README for installation and play.
