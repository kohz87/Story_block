# Story Suite v2: implementation status

Story Block 2.6 hosts Story Director 2.2 and NPC State Delta. It provides the module SDK, inventory, money, scene, data modules, pack checker, Assist and timeline. Story Director provides story-told quests, standalone checks, clock, calendar, map, World, Chronicle and arc planning.

See the README and CHANGELOG for current releases, `SPEC.md` for host interfaces, `MODULES.md` for module APIs, and `PACKS.md` for pack authoring.
